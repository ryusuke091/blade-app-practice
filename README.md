# blade-app-practice

## 概要

COACHTECH 教材 Tutorial 9-2-5「Bladeテンプレート ハンズオン演習」で作成した成果物です。商品一覧ページを表示するだけのものです。

## 使用技術

- PHP 8.5
- Laravel 10.5
- Laravel Sail (Docker Compose)
- Blade テンプレート

## 学んだこと

- 配列に(object)を付けることでオブジェクト化できること
- コレクションの存在。collect([...]);
- {{...}}エスケープ処理の存在感

## 動作確認

ブラウザから、[http://localhost/products]にアクセスして確認しました。
